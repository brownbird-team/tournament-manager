# Opis projekta

BrownBird Tournament Manager je modularni sustav za upravljanje turnirima, razvijen u sklopu kolegija Programsko inženjerstvo radi nedostatka otvorenih platformi koje podržavaju automatizaciju i povezivanje s vanjskim servisima.

Projekt je inspiriran platformom Challonge, ali je fokusiran na pružanje veće modularnosti i mogućnosti programskog pristupa.

Sustav omogućuje organizatorima lako stvaranje i upravljanje turnirima različitih formata, uključujući Swiss, Round Robin, te eliminacijske sustave. 

Ključne značajke BrownBird Tournament Manager sustava su:

- Modularna arhitektura: Sustav podržava dodavanje proširenja (pluginova) koja omogućuju autentifikaciju putem različitih vanjskih servisa koristeći OAuth2 i OpenID Connect protokole. Proširenja također mogu implementirati widgete za prikaz podataka trećih strana (npr. korisničko ime s druge platforme) izravno u sučelju aplikacije.

- Sveobuhvatno upravljanje turnirima: Podržava upravljanje organizacijama, postavljanje kompleksnih pravila turnira i upravljanje fazama natjecanja.

- Interaktivno iskustvo korisnika: Pruža komunikaciju u stvarnom vremenu putem web chata tijekom mečeva te jednostavan sustav za prijavu rezultata.

- Programski pristup (Bot API): Omogućuje vanjskim aplikacijama i alatima automatsko upravljanje turnirima putem API tokena.
